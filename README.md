# ECE 274A – Digital Logic

This repository contains example projects and coursework from ECE 274A at the University of Arizona.

The course introduces the fundamentals of digital logic and computer hardware design, including number systems, Boolean algebra, combinational and sequential logic circuits, and register-transfer level (RTL) design. Students design and analyze digital systems using Hardware Description Language (Verilog) and implement circuits on programmable hardware such as FPGAs.
